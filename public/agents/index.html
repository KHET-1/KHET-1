LATTICE AGENTS

KHET-1 OPERATION • Download → Run → Capture → Return → Display

Full Loop: End-to-End Flow

1
Download — Agent script from this page (curl one-liner or manual download)
2
Run — Execute on target device (phone/laptop). Captures network state, connections, packets.
3
Return — Results automatically POST to /api/ingest (or manually upload tarball)
4
Display — View results at /agents/results.html (auto-refreshes every 10s)

Android Agent

Captures network connections, maps processes to sockets via /proc/net, runs tcpdump if available. Works on Termux (non-root partial capture) or rooted devices (full capture).

Requires: Termux or root shell | Optional: tcpdump, python3
Download Script Copy One-Liner 
curl -sL https://workspace-star-far.vercel.app/agents/phone-capture-android.sh | bash

iOS Agent (via macOS relay)

Uses Apple's rvictl to create a virtual network interface mirroring iPhone traffic over USB. Requires Mac with Xcode + iPhone connected via USB. Also supports jailbroken iOS direct capture.

Requires: macOS + Xcode + USB connection | OR: Jailbroken iOS with tcpdump
Download Script Copy One-Liner 
curl -sL https://workspace-star-far.vercel.app/agents/phone-capture-ios.sh | bash

For jailbroken: append -s -- --jailbreak

Linux/Desktop Agent

Full Lattice Team analysis on any Linux box. Captures live traffic, traces processes, runs dual-council swarm.

Requires: Python 3, tcpdump (sudo), pyshark, pandas
Download Trace Script Copy One-Liner 
curl -sL https://workspace-star-far.vercel.app/drip_trace.sh | sudo bash 2>&1 | curl -X POST https://workspace-star-far.vercel.app/api/ingest -H "Content-Type: text/plain" -H "X-Device-ID: $(hostname)" -d @-

Manual Upload

Already have a pcap or capture results? Upload directly:

curl -X POST https://workspace-star-far.vercel.app/api/ingest \
  -H "Content-Type: application/octet-stream" \
  -H "X-Device-ID: my-phone" \
  --data-binary @/path/to/capture.pcap

Or upload JSON results:

curl -X POST https://workspace-star-far.vercel.app/api/ingest \
  -H "Content-Type: application/json" \
  -d '{"connections": [...], "processes": [...], "device": "phone-1"}'
