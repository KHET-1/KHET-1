# StarFire Forensics Toolkit — Standalone / Airgap

Self-contained network forensics pipeline. Runs fully offline. No cloud. No API calls. No telemetry. No names you don't choose to include.

## Modes

| Mode | Internet | AI | Use Case |
|------|----------|-----|----------|
| `--offline` | None | None | Pure algorithmic analysis. Court-safe. No AI involvement statement needed. |
| `--local-llm` | None | Local (Ollama) | Natural language explanations generated by a model running on YOUR hardware. Nothing leaves the box. |
| `--cloud` | Required | Remote | Full LATTICE Team swarm (current mode). Results POST to Firestar. |

## One Command

```bash
./starfire analyze /path/to/*.pcapng --offline --redact --report pdf
```

## What It Does (No AI)

1. Parses pcap/pcapng (tshark/pyshark)
2. Extracts: connections, protocols, timing, DNS, TLS SNI, payloads
3. Detects: beaconing, volume anomalies, port patterns, DNS tunneling
4. Maps: source → destination → port → service
5. Correlates: multi-file timestamp matching
6. Generates: PDF/HTML report with SHA-256 hashes, chain of custody, evidence table
7. Redacts: any field you specify (IPs → anonymized, names → [REDACTED], MACs → stripped)

## What It Does (Local LLM)

Same as above, plus:
- Plain-language explanation of findings
- Threat assessment narrative
- Recommendations in human-readable form
- All generated locally by Ollama (llama3/mistral/etc on your GPU)

## Install

```bash
# Dependencies
sudo apt install tshark python3 python3-pip
pip install pyshark pandas

# Optional: local LLM
curl -fsSL https://ollama.com/install.sh | sh
ollama pull llama3.1:8b

# Toolkit
git clone https://github.com/KHET-1/KHET-1.git
cd KHET-1/toolkit
chmod +x starfire
```

## Redaction

```bash
# Anonymize all internal IPs and hostnames
./starfire analyze capture.pcap --redact-internal

# Custom redaction map
./starfire analyze capture.pcap --redact-map redactions.json

# redactions.json example:
# {
#   "192.168.2.46": "DEVICE-A",
#   "192.168.2.151": "DEVICE-B",
#   "rathin": "[ANALYST]",
#   "Ryan": "[OPERATOR]"
# }
```

## Chain of Custody

Every run produces:
- `custody.json` — timestamped hash of every input + output
- `vault-seal.sha256` — single hash covering the entire analysis
- No network calls made (verifiable via `--audit-log` which logs all syscalls)
